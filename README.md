# 🌸 DevBloom Academy

> **An Interactive 180-Day Full-Stack, AI Engineering & Data Structures (DSA) Bootcamp Platform**

🌐 **Live Web App**: [https://devbloom.onrender.com](https://devbloom.onrender.com)

DevBloom Academy is a comprehensive, production-grade web platform designed to take developers from web foundations to building advanced Full-Stack AI applications and capstone engineering systems.

---

## 🚀 Key Features

- 📅 **180-Day Structured Curriculum**: Daily guided learning broken into 4 core phases:
  - **Phase 0**: Foundations (HTML5, CSS3, Flexbox, JS Async/Await, Git)
  - **Phase 1**: Frontend Mastery (React 19, TypeScript, State Management, TailwindCSS)
  - **Phase 2**: Backend Engineering (Express, REST APIs, SQL Databases, Auth)
  - **Phase 3**: Full-Stack AI Integration (LLM APIs, Prompt Engineering, RAG Systems)
- 🎯 **Tri-Track Daily Learning**:
  - **Full-Stack Task**: Real-world web development concepts and UI implementation.
  - **AI Track Task**: Prompting techniques, API integrations, context windows, and agent architectures.
  - **DSA Task**: Daily LeetCode-style algorithm problems with time & space complexity analysis.
- 🤖 **Bloom AI Teacher & Mentor**: Integrated AI mentorship for instant hints, code reviews, and pedagogical guidance.
- 🗄️ **SQL Database Engine**: High-performance SQLite database backend (`better-sqlite3`) for persisting user progress, daily streaks, and project submissions.
- 📆 **Interactive Calendar & iCal Export**: Personalized start date scheduling, configurable rest days, and downloadable `.ics` calendar files.
- 🎨 **Dynamic Aesthetic Design**: Customizable glassmorphism UI themes, dark mode controls, and responsive layouts.
- 🏆 **Project Hub & Skill Tree**: Built-in submission tracker for GitHub repositories, live demo links, and visual skill node progression.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, TailwindCSS, Motion, Lucide Icons, Canvas Confetti
- **Backend**: Node.js, Express, SQLite (`better-sqlite3`)
- **AI Integration**: Google Gemini API (`@google/genai`)

## ⚡ Quick Start

### 1. Prerequisites
Ensure you have **Node.js** (v18 or higher) installed on your machine.

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/lidu12/devbloom.git
cd devbloom
npm install
```

### 3. Environment Configuration
Create a `.env` file in the root directory:
```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
APP_URL="http://localhost:3000"
```

### 4. Run Development Server
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser to get started!

## 📦 Production & Deployment

### Build Application

### Run Production Server
```bash
npm run start
```
